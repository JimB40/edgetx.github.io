# Finance and Transparency

EdgeTX is an open-source community project. Financial contributions help cover the infrastructure and services needed to keep it running, alongside the time and expertise contributed by volunteers.

## What financial support helps fund

Running the project involves costs such as hosting, build services and development or test hardware. Donations help sustain this shared infrastructure and support continued development.

## Public finances

The project uses Open Collective to receive financial contributions and publish its financial activity. You can review contributions, recorded expenses and the available project balance there.

[View EdgeTX finances on Open Collective](https://opencollective.com/edgetx)

This page explains the approach; the transaction records on Open Collective are the source for current amounts and individual expenses.

## Who makes spending decisions?

The Project Steering Committee is responsible for decisions on project expenditures. Its responsibilities are described in the [Project Bylaws](bylaws.md#responsibilities). The [About page](about.md#project-steering-committee) lists the current committee members.

## Supporting the project

You can make a one-time contribution or support the project regularly through Open Collective.

[Donate through Open Collective](https://opencollective.com/edgetx/donate)

Contributing time is valuable too. Testing, documentation and development all help the project; see [Get involved](recruiting.md).
