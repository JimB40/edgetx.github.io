# Finance and Transparency

Running EdgeTX involves project expenses, including infrastructure, hosting, build services and development or test hardware. These costs are funded primarily by donations from individuals and contributions from manufacturers through the [partnership program](partnershipprogram.md).

## Financial transparency

Financial transparency is one of EdgeTX’s core values. The project uses Open Collective to collect funds and make its financial activity publicly accessible. Anyone can see the contributions received, how funds are spent and the available project balance.

[View EdgeTX finances on Open Collective](https://opencollective.com/edgetx)

This page explains the approach; the transaction records on Open Collective are the source for current amounts and individual expenses.

## Who makes spending decisions?

The Project Steering Committee is responsible for decisions on project expenditures. Its responsibilities are described in the [Project Bylaws](bylaws.md#responsibilities). The [Team page](team.md) lists the current committee members.

## Supporting the project

You can make a one-time contribution or support the project regularly through Open Collective.

[Donate through Open Collective](https://opencollective.com/edgetx/donate)

Contributing time is valuable too. Testing, documentation and development all help the project; see [Get involved](recruiting.md).
